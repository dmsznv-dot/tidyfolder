TidyFolder 0.1.2 preview: native macOS organization with preview, custom rules, persistent history and Undo.

New in 0.1.2:
- Fixed the blank interface when opening Options & exclusions. The panel now scrolls within the available window height while the action bar stays visible.
- Updated the filing-box icon with native Dock proportions, rounded corners, and a subtle metallic rim.

Requires macOS 14+. Universal compilation includes arm64 and x86_64; local runtime checks cover Apple Silicon on macOS 15.7.1. Intel runtime remains unverified.

This preview is ad-hoc signed and not Apple notarized. Gatekeeper may block downloaded copies. Developer ID signing/notarization is a remaining maintainer step before a standard public release.

No claim of exhaustive parity with proprietary Folder Tidy predicates. Start with a disposable folder. Preserve the history journal until any recovery is complete.
