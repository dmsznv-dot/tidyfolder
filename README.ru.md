# TidyFolder

Нативный сортировщик файлов для macOS на Swift 6.2, SwiftUI и AppKit. Предпросмотр перемещений, 23 встроенные категории, собственные правила с вложенными условиями, исключения и история с отменой после перезапуска.

[Скачать](https://github.com/dmsznv-dot/tidyfolder/releases) · [English](README.md) · [Совместимость с оригиналом](docs/compatibility.md)

Первая версия — **0.1.2 preview**. Это самостоятельная реализация; проект не связан с Folder Tidy и Tunabelly Software. Закрытые алгоритмы оригинала не позволяют обещать полное совпадение классификации всех файлов.

Нужна macOS 14+. Универсальная сборка содержит Apple Silicon и Intel; запуск локально проверен на Apple Silicon с macOS 15.7.1. Предварительная сборка имеет ad-hoc подпись, **без нотариализации Apple**; Gatekeeper может заблокировать загруженное приложение. Для обычного подписанного выпуска нужны учётные данные Apple Developer владельца проекта.

Выберите источник и папку назначения, нажмите «Предпросмотр», проверьте таблицу и нажмите «Сортировать». Можно использовать исходную папку как назначение. Срабатывает первое включённое правило. История позволяет отменить сортировку; занятые исходные пути и изменённые файлы сохраняются и отмечаются как конфликты.

Приложение работает локально. Настройки и журнал находятся в `~/Library/Application Support/TidyFolder`. Не удаляйте журнал до завершения восстановления. Дополнительный диагностический лог выключен по умолчанию и может содержать имена файлов и пути.

```sh
./scripts/swift.sh test --no-parallel
./scripts/build-app.sh universal
EXPECTED_ARCH=universal python3 scripts/test-release.py
./scripts/package-release.sh 0.1.2
```

Для разработки нужен Swift 6.2+. Поддерживаются Xcode и Command Line Tools. Подробности сборки, подписи и ограничений — в [English README](README.md), [проверках интерфейса](docs/manual-qa.md) и [чек-листе выпуска](docs/release-checklist.md). Лицензия MIT.
